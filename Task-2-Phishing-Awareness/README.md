# Task 2 – Phishing Awareness Presentation

## Overview

This project is a PowerPoint presentation created as part of the CodeAlpha Cyber Security Internship.

The presentation aims to educate users about phishing attacks, how to identify them, and the best practices to prevent becoming a victim.

## Topics Covered

- Introduction to Phishing
- Types of Phishing
- How Phishing Works
- Warning Signs
- Prevention Techniques
- What to Do If You Receive a Phishing Email
- Knowledge Quiz
- Summary

## Software Used

- Microsoft PowerPoint
